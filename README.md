# Next.js + Claude Code + Fly.io

Deploying Claude Code + Next.js dev app on Fly.io

## STEP 0: Prerequisites

curl -L <https://fly.io/install.sh> | sh
export PATH="$HOME/.fly/bin:$PATH"

## Log into Fly

fly auth login

Create a Fly account if you haven't: <https://fly.io>

## STEP 1: Project structure (your app)

.
├── next_app/ # Your Next.js app
├── code_api/ # Your Claude Python server
├── start_servers.sh # Start both servers
├── proxy_server.js # Reverse proxy
├── Dockerfile # Multi-stage image
├── fly.toml # Generated by Fly
├── .dockerignore # Keep your image clean
