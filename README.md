# Claude POC

This repo is a simple POC for using Claude CLI in Gitpod.

## Requirements

- Add your `ANTHROPIC_API_KEY` as a Gitpod Environment Variable: [https://gitpod.io/user/variables](https://gitpod.io/user/variables)

## How to use

1. Click "Open in Gitpod" to spin up a workspace.
2. Wait for workspace to start.
3. Open the workspace in a new tab.
4. Make the workspace shareable by clicking "Share" in the top right corner.
5. Copy the URL of the workspace and paste it into the .env of frontend app.

Live preview opens on port 5173.
Code API runs on port 8000.

[![Open in Gitpod](https://gitpod.io/button/open-in-gitpod.svg)](https://gitpod.io/#https://github.com/l4j3b/claude-poc)

See your gitpod at: [https://gitpod.io/workspaces](https://gitpod.io/workspaces)
